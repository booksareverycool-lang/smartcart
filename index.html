Welcome to SmartCart

Welcome to our science exhibition prototype! SmartCart is an intelligent AI-powered shopping companion designed to transform supermarket shopping into an effortless, budget-friendly, and optimized experience.

Explore our interactive simulator, store map route planner, hardware architecture, and exhibition quiz using the top navigation bar.

Problem Statement & Objective

The Problem: Navigating large modern supermarkets causes friction for shoppers. Finding specific items, tracking real-time cart spending against budgets, and identifying suitable dietary alternatives can be exhausting.

Our Objective: SmartCart combines automated budget calculation, real-time item dynamic tracking, smart alternative recommendations, and indoor aisle navigation into a seamless interface.

Scientific Principles Used

Artificial Intelligence

Drives smart recommendations, evaluating cart content against user-configured limits.

Natural Language Processing

Translates verbal/text query commands into structured inventory database lookup calls.

Data Processing

Indexes multi-variable datasets including item codes, price points, unit quantities, and rack coordinates.

Mathematics & Automation

Executes continuous balance calculations, dynamic threshold monitoring, and path optimization.

Hardware & Software Architecture

System architecture designed for hardware implementation on smart carts:

Microcontroller Unit

ESP32 / Raspberry Pi Module: Handles local telemetry processing, Wi-Fi sync, and sensor inputs.

Weight Sensor Load Cell

HX711 Load Cell Amplifier: Verifies added items against expected item weights to prevent checkout discrepancies.

Item Identification

Barcode Reader / RFID Scanner: Rapid scanning engine registering items instantly into the cart runtime dataset.

Backend Data Pipeline

Flask / Local JSON Schema: Lightweight HTTP microservice processing pricing and shelf coordination telemetry.
